1. Design principles

Access does not create authority

Reading a record confers no write privileges.

Spine never overwrites source data

Spine indexes and references, it does not replace.

Every consequential state is source-attributed

status + source + timestamp are inseparable.

Conflict is a first-class state, not silent overwrite

Disagreement creates HOLD, not last-write-wins.

Responsibility moves. Authority does not.

When a prescription moves to APPROVED, responsibility shifts from payer to pharmacy — but the payer retains sole authority over coverage decisions and gains no pharmacy authority. When it becomes READY, responsibility shifts to the patient for pickup, but the prescriber stops being responsible while retaining full clinical authority. The Spine tracks handoffs without transferring write privileges.

4. Conflict object

When sources disagree, do not overwrite. Example:

"conflict": {
  "detected_at": "2026-10-03T09:00:00-04:00",
  "sources": [
    {"system": "Surescripts", "value": "APPROVED"},
    {"system": "Health Plan X", "value": "NEEDS_INFORMATION"}
  ],
  "resolution_state": "HOLD",
  "responsible_actor": "SPINE",
  "next_required_action": "Reconcile with payer source of truth",
  "promotion_blocked": true,
  "hold_reason": "Conflicting authoritative sources"
}

Conflict semantics: The Spine does NOT prevent upstream systems from publishing APPROVED. It prevents promotion of that signal into the Spine's verified current_state until reconciliation.

6. Adapter mapping (v0.1)

Show how external systems feed the model without being replaced:

  • Surescripts RTPB → current_state.source = "Surescripts", status = COVERAGE_CHECK
  • CoverMyMeds PA → provenance event PA_SUBMITTED, source = "CoverMyMeds"
  • Epic MyChart → patient_action visibility
  • Zus/Particle → patient longitudinal context (read-only)
  • Redox → transport adapter, not authority

Model intent: This model implements "where is the prescription, what is blocking it, and who is responsible" with source attribution, not just PA status.
